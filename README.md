# OSINT Case Management & Reporting Framework

Uma aplicação web leve, interativa e baseada em navegador para gestão de investigações OSINT (Open Source Intelligence), estruturada em 9 fases metodológicas e gerador automático de relatórios.

## 🚀 Como Executar
Como a aplicação utiliza **React** e **Babel** via CDN para correr diretamente no navegador (sem necessidade de servidores complexos ou Node.js):

1. Faz o download ou copia o código para um único ficheiro chamado `index.html`.
2. Faz duplo clique no ficheiro para o abrir em qualquer navegador moderno (Chrome, Firefox, Edge).

## 📋 Funcionalidades Principais
* **Gestão de Alvos Múltiplos:** Permite criar, alternar e gerir várias investigações em simultâneo.
* **Metodologia de 9 Fases:** 
  1. Domain & DNS Reconnaissance
  2. IP Address & Infrastructure Analysis
  3. Subdomain Enumeration
  4. Web Technology & Server Analysis
  5. Email & Personnel Discovery
  6. Social Media & Personnel OSINT
  7. Wayback Machine & Historical Data
  8. Google Dorking
  9. Passive Reconnaissance Automation
* **Ferramentas de Cópia Rápida:** Comandos de referência rápida integrados para copiar diretamente para o terminal.
* **Gerador de Relatórios:** Compila automaticamente todos os dados registados numa estrutura de relatório profissional em formato Markdown pronta a exportar.
